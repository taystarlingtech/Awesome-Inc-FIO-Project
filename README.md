# 🌟 Awesome Inc Figure It Out Weather App 🌟

This Weather App is a web-based application that provides users with current and forecasted weather conditions for a given location. 
The app uses the Open-Meteo API to retrieve weather data and displays it in a user-friendly interface. 
The app is built using HTML, CSS, and JavaScript, and utilizes the Semantic UI and jQuery libraries for styling and DOM manipulation.

## 🚀 Features
- 📍 Location-based weather forecasting via user input
- 🌡️ Current weather conditions display
- 📆 5-day weather forecast display
- 📝 User input for location
- 🔄 Error handling for invalid locations or API request failures

## 🛠️ Tech Stack
* Frontend: HTML, CSS, JavaScript
* Libraries: Semantic UI
* API: Open-Meteo API
* Package Manager: npm
* Development Server: codesandbox.io at first, then uploaded to GitHub

## 💻 Usage
1. Open the app in a web browser: https://taystarlingtech.github.io/Awesome-Inc-FIO-Project/
2. Enter a location in the input field
3. Click the "Submit" button to retrieve the current and forecasted weather conditions
